# Todo CLI (Go)

A tiny command-line todo app I’m building to learn Go through project-based learning. The goal is to keep it simple, use the standard library mostly.

## What it does (so far)
- Add tasks from the terminal
- List tasks with an ID and checkbox-style status

## Why I made this
I wanted a small project that forces me to practice the Go fundamentals that actually matter:
modules, packages and error handling

## Getting started

### Prereqs
- Go installed (1.20+ recommended)

### Run locally
Clone the repo and run:
```bash
go run ./cmd/todo
